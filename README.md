# Hi, I'm Dylan Houston

I'm a field operations and technology professional based in **Texas**, and I build software.

By day I work in underground utility locating and damage prevention — managing high-volume 811 ticket workloads, reading utility prints, running electronic locating equipment, and training technicians in the field. On the side (and increasingly, as the main thing) I design and build software that solves the practical problems I run into in the real world.

This repo is my personal portfolio — an interactive 3D solar system you can fly around, where each planet is a section of my work and the black hole at the center is me.

## What I'm about

- **Field-tested problem solving.** 2.5+ years of utility locating, damage prevention, and technical training. I know how operations actually work because I've worked them.
- **Software that serves the field.** I build tools for the people doing the work — offline-first mobile apps, real-time ops dashboards, and workflow automation.
- **Full-stack range.** TypeScript, React, React Native/Expo, Node.js, Express/Fastify, SQLite/PostgreSQL, Three.js/WebGL, and Unity/C# for game development.

## Featured project

**[LocateMVP](https://github.com/DylanMH/LocateMVP)** — a full-stack utility locate ticket management system that models the entire 811 "Call Before You Dig" pipeline: a simulated dispatch center, an ingestion and auto-assignment backend with a 4-level geo-territory hierarchy, an offline-first field technician app, and a real-time supervisor portal.

## This portfolio

Built with React, TypeScript, Vite, Tailwind CSS, React Three Fiber, Zustand, and Framer Motion. It includes a raymarched black hole shader, orbiting section planets, adaptive quality scaling for mobile, and a 2D fallback when WebGL isn't available.

```bash
npm install
npm run dev
```
